# HOPE

![](KIP.png)

> [!NOTE]
> 각 기술 스택을 직접 사용해보며 공부하는 toy project입니다.

HOPE는 인터넷에 널리 퍼져있는 여러 개발 지식을 모아놓은 플랫폼입니다. 다양한 기술들을 직접 사용해보며 공부도 같이 할 수 있는 웹 어플리케이션을 제작해봅니다.

## 개발 환경

### Back-end

- Spring boot:3.4.4 (Java21)
    - SpringData JPA
    - Gradle
    - Spring Security
- MySQLDB
- Redis
- Docker & k8s
- Jenkins
- Apache Kafka
- RabbitMQ
- AWS

### Front-end

- React:19.0.0
